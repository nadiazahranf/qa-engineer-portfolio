# Test Cases — SIKMA

## 1. Informasi Proyek

| Informasi | Detail |
|---|---|
| Nama Sistem | SIKMA (Sistem Informasi Konter Makan) |
| Jenis Pengujian | Manual Testing |
| Pendekatan | Black-box Testing |
| Cakupan | Admin Pusat, Admin Divisi, Pihak Kantin, Karyawan |
| Aktivitas | Test Case Design, Functional Testing, Bug Reporting, Retesting |

**Catatan:** Dokumentasi ini disusun ulang secara mandiri untuk keperluan portofolio. Test case di bawah merupakan rancangan dokumentasi berdasarkan cakupan pengujian yang telah dibahas. Hasil aktual dan status belum diisi karena belum diverifikasi satu per satu.
