# Manual Testing — SIKMA

## Project Overview

Dokumentasi portofolio ini disusun berdasarkan pengalaman pengujian manual pada SIKMA (Sistem Informasi Konter Makan) saat menjalani magang sebagai Quality Assurance Intern di PT Pindad(Persero).

Pengujian mencakup empat role pengguna, yaitu Karyawan, Admin Divisi, Pihak Kantin, dan Admin Pusat, dengan fokus pada pengujian fungsional, validasi alur kerja, identifikasi bug, dan retesting.

## Testing Scope

- **Admin Pusat:** Login, persetujuan pengajuan makan, dan logout.
- **Pihak Kantin:** Login, verifikasi data pengajuan, penyelesaian pesanan, dan logout.
- **Admin Divisi:** Login, input data karyawan, pengajuan makan divisi, dan logout.
- **Karyawan:** Registrasi, login, check-in, melihat menu makan, melihat riwayat, memberikan rating, dan logout.

## Testing Activities

- Menyusun test case tertulis.
- Melakukan manual functional testing.
- Mencatat temuan bug.
- Melakukan retesting setelah perbaikan.

## Confidentiality Notice

Dokumentasi ini disusun ulang secara mandiri untuk keperluan portofolio. Dokumen internal, data perusahaan, kredensial, dan informasi sensitif tidak disertakan.
