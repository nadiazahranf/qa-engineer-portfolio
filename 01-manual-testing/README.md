# Proyek Manual Testing

Dokumentasi pengujian manual untuk simulasi sistem pengajuan makan.

Proyek ini dibuat sebagai portofolio pribadi untuk menunjukkan
kemampuan dalam menyusun test case dan melakukan pengujian fungsional.

Catatan: Proyek ini merupakan simulasi mandiri, bukan dokumentasi
resmi dari perusahaan mana pun.
