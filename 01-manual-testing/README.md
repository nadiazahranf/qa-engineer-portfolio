# Manual Testing 

## Project Overview

Dokumentasi portofolio ini disusun berdasarkan pengalaman pengujian manual saat menjalani magang sebagai Quality Assurance Intern di PT Pindad (Persero).

Pengujian mencakup empat role pengguna, yaitu Admin Pusat, Admin Divisi, Pihak Kantin, dan Karyawan, dengan fokus pada pengujian fungsional, validasi alur kerja, identifikasi bug, dan retesting.

## Testing Scope

- **Admin Pusat:** Login, persetujuan pengajuan makan, dan logout.
- **Admin Divisi:** Login, input data karyawan, pengajuan makan divisi, dan logout.
- **Pihak Kantin:** Login, pengelolaan menu makanan, verifikasi pengajuan, penyelesaian pesanan, dan logout.
- **Karyawan:** Registrasi, login, check-in, melihat menu makanan, melihat riwayat makan, memberikan rating, dan logout.

## Testing Activities

- Menyusun test case tertulis.
- Melakukan manual functional testing.
- Memverifikasi validasi input dan alur kerja sistem.
- Mencatat temuan bug.
- Melakukan retesting setelah perbaikan.

## Project Files

- [`test-cases.md`](./test-cases.md) — Dokumentasi skenario pengujian, expected result, actual result, dan status pengujian.
- [`bug-reports.md`](./bug-reports.md) — Dokumentasi bug yang ditemukan, langkah reproduksi, expected result, actual result, dan hasil retesting.
