| Item | Detail |
|---|---|
| Testing Type | UI Automation Testing |

| Test Design | Positive, Negative, Validation, Search, dan CRUD |

## 2. Tujuan Pengujian

Dokumentasi ini menjelaskan skenario pengujian otomatis pada modul Data Guru. Pengujian mencakup akses halaman, tampilan tabel, navigasi form, validasi field, pencarian data, pengelolaan role, penghapusan data, dan fungsi tabel.

Dokumentasi disusun ulang untuk kebutuhan portofolio publik. Test case tidak menyertakan kredensial, URL internal, maupun data sensitif dari lingkungan kerja sebelumnya.
